## About me

I'm a freelance Full-Stack Developer based in Buenos Aires, Argentina. I build web applications across the stack, from React interfaces to Node.js APIs and Firebase-backed data.

I'm especially interested in combining practical product development with AI features using Gemini. I value clear architecture, maintainable code, and deployments that make projects easy to try and evaluate.

## What I work with

- **Frontend:** React, JavaScript
- **Backend:** Node.js, Express, REST APIs
- **Data and AI:** Firebase / Firestore, Gemini AI, Python
- **Cloud and delivery:** Google Cloud, Cloudflare, Render
- **Tools:** Git, GitHub
